欢迎来到 **古道青阳** 的个人博客。这是第一篇文章，主要用来介绍一下本站。

本站基于 [Hexo](https://hexo.io/) 构建，使用 [Fluid](https://hexo.fluid-dev.com/) 主题，部署在 [Github Pages](https://github.com/) 上。

<!-- more -->

## 关于本站

主要用来记录：

- 📚 学习笔记
- 💡 技术心得
- 🌱 生活随想

## 常用命令

```bash
# 新建文章
hexo new "我的新文章"

# 本地预览
hexo server

# 生成静态文件
hexo generate

# 部署到 Github Pages
hexo deploy
```
